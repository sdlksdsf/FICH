What we found

Ordered by what it costs you if a stranger finds it before you fix it.

Blocker

Supabase service_role key is compiled into the browser bundle

01
Found
src/lib/supabase.ts line 6 — the client is created with a JWT whose payload decodes to "role":"service_role". It ships in /assets/index-*.js.
Impact
The key bypasses every Row Level Security policy by design. Anyone who opens DevTools on your homepage can read, edit and delete every user, message and row in your database — no login needed. This is the most severe class of leak in AI-built apps, and it is not detectable from your UI.
Evidence
const supabase = createClient(URL, 'eyJhbGciOiJIUzI1NiJ9.eyJyb2xlIjoic2VydmljZV9yb2xlIn0.••••••••')
Fix
Rotate now (Supabase → Settings → API → Reset), then move every privileged call to a server function. The browser may only ever hold the anon key. Time: 25 minutes.
Blocker

Stripe webhook grants access without verifying the signature

02
Found
api/stripe/webhook.ts — the handler parses the JSON body and acts on checkout.session.completed directly. There is no constructEvent call.
Impact
Anyone who finds the endpoint can POST a fabricated "payment succeeded" event and receive Pro access for free. Separately, because the handler is not idempotent, Stripe's automatic retries can grant the same purchase twice while the second real payment fails silently.
Fix
Verify with stripe.webhooks.constructEvent(rawBody, sig, secret), reject on mismatch, and key the grant on event.id so a retry cannot double-grant. Time: 40 minutes.
Blocker

Every table was created with Row Level Security off

03
Found
7 tables (profiles, habits, entries, subscriptions, messages, feedback, events) exist with no ENABLE ROW LEVEL SECURITY and no policies.
Impact
The anon key is public by design. With RLS off, a single request returns every row in every table. Even after the service_role key is fixed, user data stays world-readable.
Evidence
GET /rest/v1/profiles?select=* → 1,284 rows returned to an anonymous request
Fix
Enable RLS on all 7 tables, write per-user policies, then re-run the anonymous request and confirm it returns zero rows. Time: 1 hour.
Blocker

"Pro" is granted by a client-side localStorage flag

04
Found
src/hooks/usePro.ts — isPro reads localStorage.getItem('isPro').
Impact
Two clicks in DevTools unlocks every paid feature permanently, on any account. Your revenue protection is a string in the browser.
Fix
Read entitlement from subscriptions server-side, enforced by an RLS policy. The client may display the state; it must never be the source of it. Time: 45 minutes.
High

Deep links 404 on refresh

05
Found
Client-side routing with no rewrite in vercel.json. /dashboard returns 404 on a hard refresh.
Impact
Every shared link to an inner page looks broken. This is the single most common "it worked in preview" complaint, and it costs you the click you paid for.
Fix
Add the SPA rewrite to index.html and hard-refresh every route in the deploy checklist. Time: 5 minutes.
High

AI endpoint is unauthenticated and unrate-limited

06
Found
api/coach.ts proxies a model call with no session check and no per-user limit.
Impact
A single script can burn your entire monthly model budget in minutes. This is the most common way a small AI app receives its first four-figure bill.
Fix
Require a verified session, cap requests per user per hour, and set a hard spend ceiling at the provider. Time: 30 minutes.
High

No error boundary — one failed request is a white screen

07
Found
11 async calls, 2 try/catch blocks, no error boundary at the app root.
Impact
A failed fetch takes the entire app to a blank page with no message and no retry. Support tickets you cannot diagnose, and refund requests you cannot argue with.
Fix
Add a root error boundary, wrap the async paths, and surface a retry state instead of a blank screen. Time: 1 hour.
Medium

Schema exists only in the builder's chat, not in migrations

08
Impact
No environment can be rebuilt, a restore loses structure, and nobody — including you in six weeks — can state the real schema with confidence.
Fix
Dump the schema into supabase/migrations, version it, apply in CI. Time: 30 minutes.
Medium

Session token in localStorage, and secrets in console logs

09
Impact
Any injected script reads the token and takes the account over. One log line prints an env value into a third-party logging service.
Fix
Move the session to an httpOnly cookie; delete the log and log a redacted shape. Time: 40 minutes.
